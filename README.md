# Awesome RSI Resources

递归自我改进（Recursive Self-Improvement, RSI）学习与研究资源导航。

A curated directory of awesome lists, learning guides, tutorials, and courses on recursive self-improvement.

本项目汇集 RSI 相关的资源集合与学习入口，帮助读者了解每项资源适合谁、值得看什么、从哪里开始，以及内容更新到什么时候。

## 收录范围

- **研究索引与 Awesome 清单**：文献目录、综述配套仓库、可检索的研究地图。
- **指南、教材与学习路线**：概念讲解、开放教材、图解与阅读路径。
- **实践教程与 Notebook**：代码课程、可运行示例和分步练习。
- **课程、工作坊与讲座**：系统课程及配套材料。
- **评测与复现指南**：实验设计、评测方法与复现说明。

资源按主要形式分类；模型训练、Agent Harness、记忆与技能等技术方向可作为主题说明。同一项目的网站、代码、翻译与 Notebook 尽量归在一个条目下。

## 整理原则

- 给出简洁的推荐理由与具体学习入口。
- 注明语言、前置知识和实践条件，区分纯阅读、模拟演示、模型 API 调用与本地训练。
- 区分上游的实质内容更新时间与本项目的核验日期。
- 如实说明核验范围：阅读文档、检查示例或实际运行。
- 优先链接原始项目，合并普通镜像和重复条目。
