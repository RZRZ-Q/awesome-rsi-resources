# Awesome RSI Resources

**English** | [简体中文](README_zh.md)

Learning and research resources for Recursive Self-Improvement (RSI).

A curated directory of awesome lists, learning guides, tutorials, and courses on recursive self-improvement.

This project brings together RSI resource collections and learning materials to help readers understand who each resource is for, what it offers, where to start, and how current its content is.

**Last reviewed: 2026-10-23.** The collection contains 56 resources spanning awesome lists, surveys, books, tutorials, practice projects, courses, videos, and reproduction materials. This batch adds rsi_labs and a Chinese / English prerequisite notebook course, and distinguishes recursive improvement methods, related self-improvement mechanisms, and evaluation tools. A project's website, code, and notebooks are grouped into a single entry.

## Resource Scope and Labels

This directory covers both recursive improvement and the mechanisms and tools needed to study it. The following labels describe the **recommended practical entry**, with its demonstrated scope. They are our learning-oriented classification, informed by [Modern Agentic Systems §3.2](https://arxiv.org/html/2607.13104v1#S3.SS2) and [The Last AI §§2.2–2.3](https://arxiv.org/html/2609.11873v3#S2.SS2); individual papers use different definitions.

| Label | What the entry teaches | Examples in this directory |
| --- | --- | --- |
| **Recursive improvement method** | Changes to an agent implementation or improvement policy are retained and used in subsequent improvement work. We distinguish teaching prototypes from research implementations; neither label promises sustained acceleration. | [RSI Labs](#tutorials): a small improvement-policy experiment; [DGM](#practice): inherited agent code participates in later self-modification. |
| **Related self-improvement mechanism** | Prompt optimization, program search, learned adaptation, reusable experience, or co-adaptation; also introductory components and simulations. The entry explains what changes and what remains fixed. | [GEPA / TextGrad](#tutorials), [ShinkaEvolve / SEAL / Agent Lightning](#practice), [ACE / Voyager](#memory-skills), [co-evolution](#coevolution-projects), and [self-play](#adversarial-self-play). |
| **Evaluation tool** | Measures a component or illustrates acceptance criteria for a candidate change. | [LongMemEval-V2 and RSI Atlas](#evaluation); Atlas is an acceptance-gate teaching example. |

Indexes, surveys, books, and comprehensive courses remain reading resources and may span several categories. A memory benchmark or a fixed-optimizer tutorial can be useful preparation for RSI without demonstrating a recursive improvement loop. Start with the [prerequisite course](#prerequisite-courses) if needed, then compare the concrete mechanisms below.

Choose a short learning path that fits your goal:

- **Chinese learning path:** Prism's guide → Hello-Agents Reflection → optional [WalkingLabs prerequisite notebooks](#prerequisite-courses) → Hung-yi Lee's self-improvement lectures → RSI Research Notes and original surveys.
- **Concepts:** Prism's Chinese guide → The RSI Book, Chapters 1–2 → natnew's reading paths.
- **Agent engineering:** The RSI Book's Python loop → the implementations in learn-deepseek-harness → the scaffolding and evaluation sections of the selfimproving-agent survey.
- **Optimization practice:** GEPA / DSPy → ShinkaEvolve or OpenEvolve → DGM for advanced agent-code evolution.
- **Recursive improvement:** rsi_labs §4 to inspect a change to the improver's instructions → DGM to trace inherited code into subsequent self-modification. Use the prerequisite notebooks first if candidate evaluation and archives are unfamiliar.
- **Experience and memory:** Hello Generic Agent → ACE for text playbooks or Voyager for executable skills → LongMemEval-V2 for memory-component evaluation; return to the surveys for longitudinal improvement measures.
- **Training and research:** Stanford CS329A's verifier / RL readings → the foundation-model improvement sections of the selfimproving-agent survey → SEAL's adaptation loop or Agent Lightning's policy training → relevant papers from the ICLR RSI workshop.

## RL and RSI: Connections, Distinctions, and Reading Route

**RL is a way to learn behavior from reward; RSI concerns how retained improvements contribute to subsequent improvement.** They overlap, but describe different aspects of a system. Existing literature already discusses the connection: start with [Modern Agentic Systems §§3.2–3.3](https://arxiv.org/html/2607.13104v1#S3.SS3), then compare the definitions in [Towards AI §3](https://lee1003-lee.github.io/Awesome-RSI-Research/assets/rsi-survey.pdf#page=5). Some frameworks include self-generated training loops; stronger claims require improvement to the improver itself. The comparison below is this directory's synthesis, not a universal hierarchy or a claim that all RL uses a fixed architecture.

| Mechanism | What changes | What to learn from the example |
| --- | --- | --- |
| Policy learning | Policy parameters under a specified update procedure | [Agent Lightning](#practice): trace rollouts → rewards → checkpoints. Higher task reward alone does not establish that the update procedure improved. |
| Adversarial self-play | Policies and the opponents / experience they generate for one another | [OpenSpiel and SPIRAL](#adversarial-self-play): study an adaptive learning signal. Self-play specifies how experience is produced; it does not by itself specify RL, preference optimization, or changes to the learning rule. |
| Learning the RL update rule | A parameterized rule for training other agents | DiscoRL below: compare learning a better policy with learning how to update policies. A learned rule does not imply its discovery process also rewrites itself. |
| Coupled system improvement | Reusable harness procedures together with model weights | ScienceBuddy below: harness refinement shapes the next RL stage, and the updated model changes subsequent harness adaptation. |
| Self-modifying learning machinery | Policy programs that can modify their own learning behavior | Schmidhuber's self-modifying policies below: study how credit is assigned to modifications that affect later modifications. |

RL can therefore power part of an RSI loop, while code search or retained skill edits can supply other updates; [DGM](#practice) is a useful comparison without an RL weight-training step. For any project, identify **what persists, what generates the next learning signal, and whether the update procedure itself changes**. To investigate gains in the improver, compare later learning with and without the retained change under comparable tasks and budgets.

**Reading route:** Modern Agentic Systems §3.3 → the already-listed [Ashish Kumar Part 2](https://ashishkumar.ai/blog/self-improving-ai-self-play-self-training/) (the self-play template, then “Learning to learn”) → one hands-on self-play project → the three readings below. These add **three resources**; the two reused readings and this synthesis are not counted again. The research readings require no execution; the project tables separately specify runtime requirements.

## Curation Principles

- Organize the main directory by resource format, covering model training, agent harnesses, memory and skills, evaluation, and automated research.
- Label practical entries as recursive improvement methods, related self-improvement mechanisms, or evaluation tools; describe what changes and how it is reused. Keep prerequisite lessons distinct from demonstrated recursive improvement, and do not force broad surveys or courses into one category.
- Provide a recommendation, a concrete starting point, language, prerequisites, and practical requirements.
- Distinguish reading materials, simulations, real model calls, and training; record what was actually read or run during review.
- Prefer original projects; group a project's website, translations, and notebooks together, and do not count ordinary mirrors separately.
- Judge freshness by substantive content and learning value, retaining useful stable textbooks and older courses.
